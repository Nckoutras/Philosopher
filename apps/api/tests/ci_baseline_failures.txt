# CI pytest baseline — known-failing tests.
#
# THIS FILE IS EMPTY, AND THAT IS THE POINT. Every backend test passes. Any
# failure CI reports is a NEW failure, with no exceptions to weigh and no list
# to consult. The mechanism stays so a future known-broken test can be
# quarantined deliberately rather than by letting CI go red; the debt is gone.
#
# The backend-ci workflow compares the failing set against this file BY TEST ID
# and fails on any id not listed here. With no ids listed, it fails on anything.
#
# Comparison is by id, never by count — a count check cannot tell one test fixed
# plus one regressed from no change at all. That property mattered while this
# file had entries; it costs nothing now and protects the next time it does.
